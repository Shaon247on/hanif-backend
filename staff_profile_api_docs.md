# BarberBay Staff (Barber) Profile API Documentation

This document outlines the specialized APIs designed for the "Staff App" or Barber profile section.
These APIs automatically resolve data for the currently logged-in Barber. 

**Base URL:** `/api/v1/barbers/me`  
**Headers Required:** `Authorization: Bearer <your_jwt_token>`

*(Note: Since these are `GET` requests, there is no JSON Body/Payload needed. The authorization token identifies the user.)*

---

## 1. Get Profile Summary
**Endpoint:** `GET /profile/`  
**Description:** Retrieves basic details about the logged-in staff member (e.g., for the header section of the app).

**Expected Response:**
```json
{
  "success": true,
  "details": "Staff profile retrieved",
  "code": "STAFF_PROFILE",
  "data": {
    "id": 1,
    "user_id": "uuid-here",
    "name": "Mike Johnson",
    "email": "mike@example.com",
    "phone": "+1234567890",
    "specialty": "Senior Barber",
    "avatar": "https://example.com/media/profile.jpg",
    "shop": {
       "id": 1,
       "name": "Hampdenpark Barber"
    }
  }
}
```

## 2. Get Offered Services
**Endpoint:** `GET /services/`  
**Description:** Retrieves the list of services this specific barber offers.

**Expected Response:**
```json
{
  "success": true,
  "details": "Staff services retrieved",
  "code": "STAFF_SERVICES",
  "data": [
    {
      "id": 1,
      "name": "Haircut & Fade",
      "duration_minutes": 45,
      "price": "35.00"
    },
    {
      "id": 2,
      "name": "Face Wash",
      "duration_minutes": 15,
      "price": "10.00"
    }
  ]
}
```

## 3. Get Working Days & Hours (Schedule)
**Endpoint:** `GET /schedule/`  
**Description:** Retrieves the weekly working shifts for the barber.

**Expected Response:**
```json
{
  "success": true,
  "details": "Staff schedule retrieved",
  "code": "STAFF_SCHEDULE",
  "data": [
    {
      "id": 1,
      "day_of_week": "monday",
      "start_time": "10:00 am",
      "end_time": "05:00 pm",
      "is_active": true
    },
    {
      "id": 2,
      "day_of_week": "thursday",
      "start_time": "10:00 am",
      "end_time": "05:00 pm",
      "is_active": false
    }
  ]
}
```

## 4. Get Break Schedule / Time Off
**Endpoint:** `GET /time-off/`  
**Description:** Retrieves approved/pending sick leaves or time-offs for the barber.

**Expected Response:**
```json
{
  "success": true,
  "details": "Staff time off retrieved",
  "code": "STAFF_TIME_OFF",
  "data": [
    {
      "id": 1,
      "reason": "Sick leave",
      "start_date": "18 Jul",
      "end_date": "20 Jul",
      "status": "approved"
    },
    {
      "id": 2,
      "reason": "Family vacation",
      "start_date": "25 Aug",
      "end_date": "30 Aug",
      "status": "pending"
    }
  ]
}
```

## 5. Get Staff Reviews
**Endpoint:** `GET /reviews/`  
**Description:** Retrieves only the reviews left by customers for this specific barber, including a rating distribution summary.

**Expected Response:**
```json
{
  "success": true,
  "details": "Staff reviews retrieved",
  "code": "STAFF_REVIEWS",
  "data": {
    "summary": {
      "average_rating": 4.9,
      "total_reviews": 120,
      "distribution": {
        "1": 0, "2": 2, "3": 3, "4": 15, "5": 100
      }
    },
    "reviews": [
      {
        "id": 101,
        "rating": 5,
        "comment": "Best barber in town, great fade!",
        "customer_name": "John",
        "customer_avatar": "https://example.com/media/john.jpg",
        "date": "20 Jul 2026"
      }
    ]
  }
}
```

## 6. Get Reports (Revenue & Booking Stats)
**Endpoint:** `GET /reports/`  
**Description:** Retrieves the total completed bookings, total revenue generated by the barber, and a history of past appointments.

**Expected Response:**
```json
{
  "success": true,
  "details": "Staff reports retrieved",
  "code": "STAFF_REPORTS",
  "data": {
    "total_bookings": 25,
    "total_revenue": 6780.00,
    "history": [

        "id": 1,
        "customer_name": "Trump",

        "price": 40.00,

      },

        "id": 2,
        "customer_name": "Biden",
        "service_name": "Haircut",
```
